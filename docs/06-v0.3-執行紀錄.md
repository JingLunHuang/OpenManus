離線資料與真實資料應分開看：目前 W1 的成功率來自固定劇本，W2 的 0.940 包含合成 token 成本；兩者只驗證管線與接受閘門。完整實驗產物可從 [實驗報告](../experiments/report.md) 找到逐題結果，再用 `lingxi replay` 查看個別 `events.jsonl`。
看板的「KV 重用」是本地前綴估計；W1 報告中的供應商 `cached_tokens` 為 0，兩者不可視為同一指標。

## 離線重現

```powershell
.venv\Scripts\python scripts\experiments\run_experiment.py --suite smoke --provider scripted
.venv\Scripts\python scripts\experiments\run_experiment.py --suite main --provider scripted --repeats 3
.venv\Scripts\python -m lingxi.cli stats --runs-dir "experiments\runs\<執行目錄>\memory-on\runs"
.venv\Scripts\python -m lingxi.cli --config "<隔離設定檔>" evolve round --with-e2e
```

整理前曾以離線測試套件驗證 100 項全數通過；依後續清理要求，測試原始碼已移除。
現行重現入口是離線冒煙、完整實驗與受保護評測，夾具資源放在 `lingxi/evaluation/`。
`docs/02`、`docs/04` 與既有實驗封存報告若提及 `tests/`，屬清理前的歷史路徑；現行路徑以本節和實驗說明為準。

## English summary draft

LingXi is an evidence driven browser agent built on OpenManus. It combines page perception, grounded actions, a findings board, iterative fact checking, memory, and a guarded improvement loop. The current v0.3 results are reproducible offline demonstrations using scripted model replies and local fixture pages; real model effectiveness and cost remain to be measured.

## 三分鐘展示講稿

**0:00–0:30｜問題。** 一般瀏覽器代理容易在頁面變動後點錯元素，也可能把單一來源的數字直接當成結論。靈犀讓每個動作與答案都留下可復盤的證據。

**0:30–1:10｜感知與操作。** 展示 Web 執行頁：本步簡報按元素用途分組，`#編號` 對應 DOM 元素；切換分頁後編號會落在另一個命名空間，舊分頁編號無法誤點到新頁。

**1:10–1:55｜發現與查證。** 展示發現板的「單一來源／多方印證／有矛盾」。提交 `finish` 時，查證員會指出重要單一來源數字；內核最多補查三條，再決定放行或退回。打開黑匣子，指出搜尋、閱讀、預算與查證事件。

**1:55–2:30｜記憶與改進。** 說明 LightMem/FluxMem 的寫入、召回與整理；RSI 用受保護套件檢查候選變更，版號與接受理由寫入帳本，可回滾。

**2:30–3:00｜量測與邊界。** 展示 W1 對照報告與穩定性看板：目前是固定劇本、每題三次的離線結果，可證明流程重現；真實模型的記憶增益、第二來源成效與跨站調研仍需後續實測。
